# اعتبارسنجی مستندات و شواهد

مبنای این گزارش commit `e57f8606b3ca03c04bce9cd8d2d4bc5da48efeb1` در شاخهٔ `codex/documentation-audit` و نوع پروژهٔ `service-mobile` است.

## کنترل‌های انجام‌شده

- مسیرهای tracked با `git ls-tree` استخراج و به `docs/project-guide/inventory.json` منتقل شدند.
- مسیرهای شبیه secret، دادهٔ خام، dump، کلید و خروجی build عمداً در inventory حذف و فقط شمارش آن‌ها ثبت شد.
- لینک‌های راهنمای پروژه و فرمت JSON باید پیش از تحویل بررسی شوند.

## نتیجه

این فایل اعتبارسنجی مستندات است، نه نتیجهٔ تست محصول یا پذیرش production. آزمون‌هایی که واقعاً اجرا نشده‌اند `NOT_RUN` محسوب می‌شوند. وضعیت CI، runtime، داده، امنیت و استقرار باید با شاهد مستقل همان SHA ثبت شود.

## محدودیت

طبقه‌بندی فایل‌ها بر اساس نام مسیر است و reachability، قرارداد کامل API، صحت runtime یا پوشش آزمون را ثابت نمی‌کند. دادهٔ واقعی، secret و credential در این مستندات ثبت نشده است.

## اجرای اعتبارسنجی ۳۰ اکتبر ۲۰۲۶

- نصب `web` با lockfile شروع شد اما به علت خطاهای شبکه/registry و tarballهای ناقص تکمیل نشد.
- بنابراین lint، stylelint، prettier، typecheck و تست web قابل اجرا نبودند.
- قراردادهای API و تست‌های موجود نیازمند تکمیل نصب وابستگی‌ها هستند.
