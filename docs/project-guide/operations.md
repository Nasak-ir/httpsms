# عملیات و امنیت

کلید حساب و گوشی، شماره‌ها، متن پیام و credentialهای Firebase حساس‌اند. راهنمای تنظیم، سلامت و backup در [سند اصلی](../NASAK_SMS.md) آمده است. ارسال واقعی ممکن است هزینه یا اثر بیرونی داشته باشد و در این بررسی انجام نشد. checkout عملیاتی سرور دارای تغییرات محلی است و با این commit معادل فرض نمی‌شود؛ هیچ تغییری در آن داده نشده است.
