# کارهای باز

نسخه و تغییرات checkout فعال، وضعیت گوشی و صف، قرارداد webhook، امنیت کلید و بازیابی backup نیاز به بررسی مستقل دارند. در ۲۹ اکتبر ابزار graphify در محیط موقت نصب و برای شناسایی مدل پیام و صف استفاده شد؛ تحلیل جامع کد و آزمون اجرا همچنان انجام نشده است.

## کارهای باقی‌مانده از اعتبارسنجی ۳۰ اکتبر ۲۰۲۶

- تکمیل `pnpm install --frozen-lockfile` در محیط با دسترسی پایدار به registry.
- اجرای `pnpm lint`، typecheck (در صورت وجود فرمان پروژه)، تست و بررسی قراردادهای API پس از نصب.
